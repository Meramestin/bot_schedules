# Telegram бот расписания вуза

Бот получает код группы, скачивает страницу расписания с сайта вуза и показывает занятия в стиле как на скриншоте: сразу вся неделя (Пн–Вс) и кнопки переключения недель.

## 1) Установка

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## 2) Настройка

```bash
cp .env.example .env
```

Заполните:
- `BOT_TOKEN` — токен от BotFather.
- `SCHEDULE_URL_TEMPLATE` — ссылка на страницу расписания, где `{group}` заменяется на код группы.
  - Для МАИ можно сразу использовать: `https://mai.ru/education/studies/schedule/index.php?group={group}`
  - Код группы будет URL-encoded автоматически (например, `М8О-118БВ-25`).
- `TZ` — часовой пояс (по умолчанию `Europe/Moscow`).

## 3) Запуск

```bash
python bot.py
# В боте: отправьте код группы или /week для текущей недели
```

## Важно про парсинг

Парсер реализован в `schedule_service.py` и по умолчанию ожидает HTML-узлы:
- `.schedule-day[data-date="YYYY-MM-DD"]`
- внутри `.lesson` с полями `.subject`, `.teacher`, `.time`, `.kind`, `.room`

Если на сайте вуза другая структура, поменяйте селекторы в `parse_day`.


## Если бот пишет «Выходной» каждый день

Скорее всего, HTML-структура страницы не совпала с парсером.
В текущей версии добавлен fallback-парсинг по тексту дня/времени, а при полном несовпадении бот пишет явную ошибку парсинга вместо ложного «Выходной».


## Поддержка структуры МАИ

Добавлен отдельный разбор для структуры страницы МАИ:
- день: `li.step-item` + `span.step-title` (например, `Пн, 20 апреля`)
- занятие: блок `div.mb-4`
- дисциплина: `p.mb-2`
- время/преподаватель/аудитория: `ul.list-inline > li.list-inline-item`
